# 🐝 Jenter planer

Aplikacija za praćenje odgoja matica Jenter sistemom – tri jentera (Jenter-1, Jenter-2, Jenter-3), automatski datumi aktivnosti i raspored smjena (S1, S2, D, N).

- Svaki jenter ima svoj datum ubrizgavanja matice.
- Smjene se podešavaju u ⚙️ podešavanjima (referentni datum, smjena tog dana i redoslijed).
- Radi bez interneta i može se instalirati na telefon kao aplikacija.
- Podaci se čuvaju lokalno na uređaju.

## Objava na GitHub Pages

1. Napravite repozitorij na github.com (npr. `jenter-planer`), javni (Public).
2. Učitajte sve fajlove iz ovog foldera (Add file → Upload files).
3. Settings → Pages → Branch: `main`, folder `/ (root)` → Save.
4. Nakon 1–2 minute aplikacija je na `https://VASE-KORISNICKO-IME.github.io/jenter-planer/`.
